# Home Repo 定期維護

1. 讀 [maintenance/state.md](../../../maintenance/state.md)。不是 `status: enabled` 時，只有 owner 當次明確要求才執行單次整理，且不改變狀態。
2. 依 [maintenance.md](../../../guides/maintenance.md) 的「每次執行」逐步處理，嚴守授權的預算、資料範圍與修改類型。
3. 反思依 [reflection.md](../../../guides/reflection.md)；超出授權的變更依 [review.md](../../../guides/review.md) 提案或列入 owner decision。

完成條件：checkpoint、剩餘清單與執行紀錄已更新，並依授權與本次修改一起 commit；回報修改、提案、待決定與剩餘項目。
