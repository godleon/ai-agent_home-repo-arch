# Home Repo 初始化

1. 讀 [initialization.md](../../../guides/initialization.md)，從第 1 步開始逐步執行；每步達到完成條件才進下一步。
2. 第 1 步確認 Git top level 不是本實例根目錄時立即停止，不寫入任何檔案。
3. 角色設計讀 [roles.md](../../../guides/roles.md)；harness 細節讀 [adapters](../../../adapters/) 中對應的檔案。
4. 套用設定、付費 smoke、安裝排程或 extension、加入 remote，都要先取得 owner 對該項的明確同意。

完成條件：[SETUP.md](../../../SETUP.md) 已記錄每一步的結果或受阻原因，回報時分開列出已配置、已讀回、已實測與未驗證項目。
